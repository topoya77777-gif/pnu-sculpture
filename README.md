# 부산대 조소과 과실 게임

친구들끼리 접속해서 노는 도트 과실 게임 웹앱이에요.
주소: https://topoya77777-gif.github.io/pnu-sculpture/

## 파일
- `index.html` : 게임 전부 (그림·코드가 다 들어 있어요). **고칠 때는 이 파일을 고쳐요.**
- `config.js` : Firebase(pnu-sculpture) 연결 설정
- `firebase-shim.js` : 게임이 Firebase로 저장·실시간 접속을 하게 이어주는 부분 (초대 코드, 관리자)
- `database.rules.json` : Firebase 데이터베이스 보안 규칙 (Firebase 콘솔에 붙여 넣어 쓰는 사본)
- `manifest.webmanifest`, `icon-*.png` : 아이폰 홈 화면에 추가할 때 쓰는 이름·아이콘
